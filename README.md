# credit-card-fraud-detection-
A machine learning project for detecting fraudulent credit card transactions using data preprocessing, exploratory data analysis, and classification models.💳💳

 # Credit Card Fraud Detection
 ## Problem Statement Credit card companies need to catch fraudulent transactions quickly to protect customers from unauthorized charges. 
 ## Dataset - Kaggle: mlg-ulb/creditcardfraud - 284,807 transactions, only 492 are fraud (0.172%) - Features V1–V28 are anonymized, plus Time and Amount.
 ## Exploratory Data Analysis ![Class imbalance](results/class_imbalance.png) Only 492 out of 284,807 transactions are fraud — this extreme imbalance is the core challenge of this project.
